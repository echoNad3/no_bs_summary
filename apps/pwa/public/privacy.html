Privacy

Updated August 29, 2026

No ads. No analytics. No tracking. No accounts. No data sales.

Data used

  • The URL and title of the active YouTube video.
  • The shared app password.
  • The captions needed to make the summary.
  • The public network address needed to enforce passwordless free-use limits.

The PWA keeps the password, text size, and latest result in local browser storage. The extension keeps the password and latest result on that device; only the text-size setting may use Chrome Sync. It only reads supported YouTube tabs. Video titles stay on the device for display and copying; they are not sent to the summary backend.

YouTube receives normal request data when the app loads a video thumbnail.

Processing and storage

The backend uses TranscriptAPI for captions and Google Gemini for the summary. Gemini storage is off. Cloudflare KV stores the finished summary, verdict, language, timing, and video ID so repeats are free. Full transcripts and the app password are not stored in the cloud. Before quota storage, the backend replaces the network address with a keyed hash. Cloudflare Durable Objects store only that hash plus daily and monthly usage counters; old counters are removed after their period ends.

Sharing

Cloudflare, TranscriptAPI, Google, and Chrome Sync process only the data needed to run the app. Data is not sold or used for ads or credit decisions.

Chrome Limited Use

Use and transfer of Chrome API data follows the Chrome Web Store User Data Policy, including its Limited Use requirements. It is used only to provide and secure the feature you request.

Delete or contact

Remove the app or extension to clear local data. Clear Chrome Sync through your Google account. For cached-summary deletion or privacy questions, open an issue on GitHub.
