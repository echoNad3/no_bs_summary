No BS Summary

Last updated: July 16, 2026

No BS Summary turns the captions from a YouTube video into a detailed summary. It has no ads, analytics, tracking, accounts, or data sales.

What the Chrome extension handles

  • The URL and title of the active YouTube video.
  • The caption language you choose.
  • The shared app password you enter.

The extension reads the active tab only on supported YouTube hosts. It sends the items above to the No BS Summary backend only when you click “Cut the BS.” The app password is saved in Chrome Sync so you do not have to enter it every time. The extension does not read page contents, browsing history outside those YouTube hosts, cookies, or personal files.

How the backend uses data

The backend extracts the YouTube video ID, asks TranscriptAPI for the requested captions, and sends the video title, caption language, and caption text to Google Gemini to create the summary. Gemini requests set storage off. Full transcripts and the app password are not stored by No BS Summary.

The finished summary, verdict, timing, language, and video ID are cached in Cloudflare KV without an automatic expiry so repeat requests are fast and do not create another paid API call. Cloudflare, TranscriptAPI, Google, and Chrome Sync process data under their own privacy and security terms.

Sharing, selling, and advertising

Data is shared only with the processors named above to provide the requested summary. It is never sold, used for ads, used for credit decisions, or given to humans to read except when required for security, abuse investigation, or law.

Limited Use

No BS Summary’s use and transfer of information received from Chrome APIs follows the Chrome Web Store User Data Policy, including its Limited Use requirements. Data is used only to provide and secure the summary feature the user requests.

Deletion and contact

Remove the extension to delete its local Chrome data. Chrome Sync data can also be cleared through your Google account. To ask the owner to delete a cached summary or report a privacy problem, open an issue on the project’s GitHub repository.
